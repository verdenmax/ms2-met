# 逐电荷、独立峰和主峰内序列结构：开发验证协议

状态：实验设计、输入核查、Q/D/S v1 特征提取实现、案例回归及五臂验证执行入口已完成，尚未在真实数据上全量提取新特征或运行本轮训练。实现定义与命令见 [Q/D/S 特征说明](../../../docs/specs/2026-09-12-fragment-structure-features.md) 和 [验证流水线](../../../docs/specs/2026-09-12-fragment-structure-validation.md)。本文限定首轮验证，后续对参数/特征的修改需另记版本，不能覆盖原结果。

## 要回答的问题

在相同真实 PSM、相同冻结 group、相同训练和阈值校准方式下，新信息是否能让模型检出更多 entrapment 错误，同时控制对标注正确鉴定的误报？

不能只统计此前 130 条 FN 中找回多少。必须同时统计原来检出的 trap 有多少变成新的 FN，并核查全部正确鉴定的 FP 变化。130 条及其参考已经用于人工发现假设；对这批数据的交叉验证属于开发验证，不能称为全新的独立确认。

## 数据与分组

输入已核对，见 [feature_validation_readiness.json](feature_validation_readiness.json)。

- 使用现有 effectiveness manifest 的 `experiment_origin=real_q01` 行及既有 `evidence_observed` cohort。
- 全量为 107,227 条：106,666 条标注正确、561 条 trap。新特征提取必须覆盖这个冻结集合；失败行保留并显式记录，不能按特征质量删样本。
- 沿用 `leakage_group_id` 和 `experiment_outer_fold`，不按 Rep 重划，不重新随机拆肽段。检查每个 group 只属于一个外层折、所有相关的肽段/电荷/Rep/生成家族不跨训练测试。
- 五折轮流留出；每条样本恰好得到一次外层预测。每轮约四折作开发训练、一折作外层测试；这里的 80% 是外层训练候选池，内部还会划分拟合、早停和阈值校准数据。
- 首轮用 M-Real 的训练底表：训练侧的真实正确鉴定和真实 trap。首轮回答特征是否有增量信息。
- 原存储标签保持不变，不因为人工发现疑似真实外源来源而删除或改标 25 条源蛋白聚集样本。可以附加明确标注的敏感性描述，不能据此选择优胜模型。

## 先实现的三个特征组

旧字段保留原含义，尤其不能把 `y_count` 悄悄改成 Q1A 通过数量。所有新字段只依赖当前 PSM、标记规则和对应谱图，不输入另一候选、搜索分数、物种、来源引擎、FN 编号或测试标签。

| 特征组 | 新信息 | 主要核查点 |
| --- | --- | --- |
| Q：逐电荷证据 | 分别计算 1+/2+ 的轻重相关和配对；同电荷有效支持数；pooled 通过却无同电荷通过的比例；两侧主导电荷及比值差 | FN007、FN033、FN129；排除超过前体电荷的碎片电荷；空信号不变成完美相关 |
| D：独立峰证据 | 同一候选内部同一实测峰的重复使用；去重前后支持数和重复强度比例 | FN008、FN018–020、FN091、FN111–113；峰来自同一 scan/实测 centroid 才可认作重用，质量容差窗重叠本身不够 |
| S：主峰内序列结构 | 轻重两侧共同成立的候选内部主峰组；该组支持的序列切点、互补切点、连续片段、内部 K/R 标记位置；主峰外支持比例 | FN039、FN082、FN102；使用峰宽、采样和强度解释周期偏差，不把一周期框外统一判错 |

S 的基础计算可以调用同电荷、去重后的证据表示，但其模型输入仅限序列结构字段；Q、D 的汇总字段不自动加入 S 单组模型。因此“S 单组收益”表示这些结构字段的收益，不表示其底层计算完全不依赖电荷或去重。

第一版宜保持小而可解释的特征集合。阈值、聚类宽度、弱峰处理等若需要选择，只能在外层训练侧的内层 group 验证中选择；不能逐条调到拒绝这 130 个 FN。有效证据为 0 与因不可适用而缺失要分开，未定义的相关性/离散度保留缺失状态。

## 第一轮五个模型

共同基线 B 使用原 `ms1_ms2_no_prediction` 特征注册表与冻结输入列；所有臂用相同训练样本、特征列顺序规范、超参数、随机种子和内层 group 划分。

| 臂 | 特征 | 回答的问题 |
| --- | --- | --- |
| B | 当前 MS1/MS2 特征 | 复现基线 |
| B+Q | 基线＋逐电荷 | 电荷汇总丢失的信息是否有用 |
| B+D | 基线＋独立峰 | 重复使用信号是否影响判断 |
| B+S | 基线＋主峰内序列结构 | 位置结构是否有用 |
| B+Q+D+S | 全部 | 组合信息是否有增量价值 |

预先指定主比较为 `B+Q+D+S` 对 B，其余三个单组比较用于定位作用来源。组合优于单组不能自动说明每组都必要；若组合有收益，再作逐组去除的消融。特征重要性或 SHAP 不作为效用成立的依据。

B 需要按本次固定训练协议运行。只有训练参数、样本、内层划分、特征定义及实现版本均相同时，才可直接复用以前的模型；不把不同 recipe 的旧分数与新模型硬比较。

## 阈值、结果及判读

复用 `tools/spec_trainer/src/cv_core.py` 及现有正式训练器的 group/早停/校准流程，不复制另一套混淆矩阵定义。

- 存储：`label=1` 正确，`label=0` 错误；模型输出 trust。
- 评估：`error_truth=1-label`，`error_score=1-trust`，错误鉴定为正类。
- 每个外层训练池内使用相同的五个成员划分；每个成员在自己未参与拟合的 OOF 校准数据中，以实际正确 IDs 校准 FPR 1%、5%、10% 的 error threshold。
- 成员阈值只能施加于对应成员分数，最后按多数投票作外层决策。禁止用单模型 OOF 阈值直接切平均 ensemble 分数。
- 主表读取 `operating_points.fpr_5.external_ensemble`：这是“训练侧校准 FPR5 后，测试上实际观测到的 FPR/FNR”，不保证测试 FPR 恰好等于 5%。
- 外层测试标签参与的精确 FPR5 ROC 点如需展示，放在 `retrospective_test_working_points` 并标记 oracle/non-deployable，不能用它替换正式决策。
- 标准排序和工作点指标均沿用规范：`roc_auc`、`error_pr_auc`、`fnr_at_fpr5`、`error_recall_at_fpr10`，以及 FPR1/5/10 工作点；区分回顾性 ROC 指标与正式外部投票结果。
- 每个机器可读结果包含 `metric_semantics=error_identification_positive_v1`、`positive_class=incorrect_identification`。

每个模型都输出下表，而不是只展示找回的旧 FN：

| 必报量 | 解释 |
| --- | --- |
| 实际测试 FPR、FP 数 | 正确鉴定被误伤多少 |
| 实际测试 FNR、FN 数 | trap 仍被漏掉多少 |
| 原 FN → 检出数 | 找回的旧错误 |
| 原检出 → 新 FN 数 | 新增漏错 |
| 净找回 | 前两种 trap 转移相减，等于基线 FN 数减去新 FN 数 |
| 旧正确接受 → 新误报，以及旧误报 → 新接受 | 是否通过多报错换来 trap 召回 |
| 各外层折、各 group 的配对变化 | 收益是否集中在少数家族 |

解释时以同一测试行的配对差值为准。按 `leakage_group_id` 做配对 cluster bootstrap，保持同一组内样本共同抽样；不能把 5 折的标准差当作独立重复实验的置信区间。区间仅描述这批冻结 OOF 预测上的差值不确定性，不消除人工挑选假设的偏差，也不完整反映重新训练的不确定性。

开发筛选的预声明参考线：主比较 error recall 净增加至少 3 个百分点（561 条 trap 约对应净找回 17 条），同时实际 FPR 增量不超过 0.5 个百分点。两项均报告配对区间；只有 recall 增益下界>0、FPR 增量上界≤0.5 个百分点才称为本批开发数据支持继续验证。若点估计有利但区间不足，结论为“有候选信号，证据不足”。这些是本轮开发参考线，不是沿用旧 effectiveness 的 +1 个百分点界限，也不是对独立测试有效性的承诺。

主比较预先固定；单组结果是探索性比较，不能从四个臂中挑最好的再沿用未校正的主比较显著性。任何进一步的正式多臂统计声明需预先定义相应的多重比较控制。

## 与已完成预测特征实验衔接

第一轮的观察特征实验覆盖全部 561 条 trap，便于核对 130 条旧 FN 的转移。随后在完全相同的 `has_lib_pred=1` cohort 上，比较“当前＋自身预测谱”与“当前＋自身预测谱＋选定结构组”。两者须重新使用一致的训练协议。

该共同 cohort 为 89,643 条：89,156 条标注正确、487 条 trap。不能把这里的 FN/FNR 与全量 107,227 行实验直接相减。此比较回答：新结构是否在已有预测谱信息之外仍有增量价值。预测器上游训练数据未完全可审计的限制继续保留。

## 判断边界

目前已有的 130 FN / 130 匹配参考缓存只用于实现验算和已知案例回归，不能拿来训练后宣称有效，也不能因参考中的出现率较低直接宣布某指标能分辨真假。

已知反例需要保留：同电荷配对缺口在参考组也出现；无互补切点在两组频次接近；FN097 等强支持条目的真实身份仍未解决。因此检验对象是可组合的信息增量，不是“满足某个手工条件即为 trap”。

开发结果有收益后，再冻结特征、模型和阈值，到未用于本轮开发的数据做确认。新数据仍按已有家族分组规则去除训练/校准与测试间的重合，不按 Rep 简单留出。这一步才能支持更强的独立泛化结论。合成负样本生成器的改进另作固定特征下的训练样本对照。

## 执行顺序和产物

1. 全量提取 Q/D/S 的底层逐离子证据，缓存结果；保留旧特征，按稳定样本 ID 合并。对照 FN007、FN129、FN091、FN102 及强支持参考，验证实现与谱图一致。
2. 冻结特征清单、输入/manifest 指纹、内层划分、模型参数和本协议；生成五个臂的训练配置。
3. 运行五臂 group 外层验证，保存每行的成员分数、阈值、投票和旧新转移表。
4. 输出开发阶段比较报告，再决定是否进入预测特征增量实验和独立确认。
