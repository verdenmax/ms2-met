> 状态：待评审

## 一、研究背景与定位

### 1.1 问题陈述

蛋白质组学搜索引擎（DIA-NN、AlphaDIA 等）通过将实验谱图与理论谱图匹配来鉴定肽段。目前主流的质量控制方法是 **Target-Decoy Approach (TDA)**：在数据库中加入反向（decoy）序列，通过搜索结果中 decoy 的比例估算 False Discovery Rate (FDR)。

TDA 存在以下结构性局限：

1. **假设依赖**：TDA 假设 decoy 与 target 在干扰分布上等价。该假设在 DIA 宽窗口、稀有修饰、非典型肽段等场景下可能失效。
2. **盲点**：TDA 给出全局 FDR 估计，**无法标识具体哪些 PSM 是错的**——它只能说"这一批里有 1% 是错的"，不能指出是哪一条。
3. **缺乏独立性**：TDA 与搜索引擎使用同一套谱图证据（谱匹配），没有真正的外部验证。

### 1.2 本工具的定位

**ms2-met 是 TDA 的独立第二意见**——对搜索引擎已鉴定的每一条轻标 PSM，基于一种与谱匹配机制无关的物理证据（SILAC 配对），独立判断其可信度。

具体而言：利用 SILAC 标记实验中"轻标和重标必须成对出现且具有可预测物理关系"这一事实，对搜索引擎给出的每条轻标鉴定，去原始数据中寻找重标证据。若证据充分 → 鉴定可信；若证据缺失 → 鉴定可疑。

### 1.3 核心论点

> **对于已鉴定的轻标 PSM，我们由其序列推导出对重标信号的多维联合预测，并在数据中检验这些预测是否被独立证据同时满足。**

该论点的关键性质：

- **独立性**：SILAC 配对所依赖的物理事实（轻重标的化学等价性导致的 RT/形状/比例一致）与搜索引擎的谱匹配机制完全独立。
- **多维**：质量、时间、强度、形状、序列等多个测量维度构成联合约束。
- **可校准**：每个维度都有明确的预测值与实测值的偏差度量，可给出基于物理的、不依赖 decoy 的置信度。

### 1.4 与 TDA 的互补关系

| 维度 | TDA | SILAC-validation |
|------|-----|------------------|
| 证据来源 | decoy 分布 | 物理预测 vs 实测 |
| 校准类型 | 全局 FDR | 单 PSM 置信度 |
| 关键假设 | decoy 代表 target 的干扰分布 | 轻重标化学等价 |
| 主要失败模式 | decoy 分布偏离时校准失效 | 真实共流出肽段恰好同时满足全部预测 |
| 适用域 | 大规模筛选 | 关键鉴定的独立验证 / TDA 校准检查 |

二者是**正交互补**的关系。当二者结论一致 → 高置信；当二者结论不一致 → 高信息量的研究案例，可用于发现搜索引擎或 TDA 的系统性问题。

## 二、理论框架

### 2.1 视角 A vs 视角 B——判据形式的根本区别

任何特征的本质都可归入两类形式之一：

**视角 A（相似度判据）**

- 形式：`feature(observed_light, observed_heavy_candidate) → similarity_score`
- 本质：对称地比较两个观测信号的相似度
- 典型例子：`Pearson(light_xic, heavy_xic)`
- 弱点：任何形状相似的真实信号都能通过——包括无关肽段

**视角 B（精度判据）**

- 形式：`feature(observed, L's_prediction) → deviation`
- 本质：度量实测信号偏离 L 预测的程度
- 典型例子：`mz_avg_err = |observed_mz - L_predicted_mz| / predicted_mz` (ppm)
- 强点：L 的预测值直接进入判据，干扰必须精确命中预测位置才能通过

**核心原则**：每个特征设计时都应能回答以下问题：

1. L 在这个维度上的预测值是什么？（一个具体的数）
2. 我的特征是不是在度量实测值与该预测值的偏差？
3. 如果是 → 视角 B；如果只是在比较两个观测信号的相似度 → 视角 A。

### 2.2 L 对 H 的完整预测——按物理量分类

L 对其重标对应物 H 的预测可按测量轴分为 5 类：

**类 1：质量轴预测**

- **前体 m/z**：每个电荷态一个精确值，由 L 序列和 SILAC 标记的 Δm 决定
- **同位素包络**：M、M+1、M+2、M+3... 的相对强度，由肽段元素组成精确预测
- **碎片 m/z**：每个 b/y 离子是否平移 Δm，取决于该离子是否包含 K/R 残基——这构成一个序列特异的位掩码模式

**类 2：时间轴预测**

- **保留时间**：RT_H ≈ RT_L（理论上化学等价，偏差仅来自微小同位素效应）
- **峰宽**：相同色谱条件下相近
- **Apex 时刻**：apex_H ≈ apex_L

**类 3：形状轴预测**

- **前体 XIC 形状**：H 的前体 XIC 与 L 的前体 XIC 高度共流出
- **碎片 XIC 形状**：每个碎片各自有自己的 XIC，都应与 L 对应碎片共流出

**类 4：强度轴预测**

- **L:H 总强度比**：由样本混标比决定（如 1:1）
- **跨碎片强度比一致性**：所有成功配对的碎片应共享同一个 H/L 比例
- **电荷态分布**：H 应在 L 出现的所有电荷态都可见

**类 5：序列签名预测**（最强但最被忽视）

- **碎片 Δm 模式**：L 的 N 个 b/y 离子中，哪些应平移、哪些不应——构成 N 位二进制签名
- **同位素峰间距模式**：1.00335 Da 等差数列
- **多电荷态共存模式**：跨电荷态 RT 一致

### 2.3 独立性结构

#### 真正独立的三条物理轴

| 物理轴 | 噪声来源 | 干扰需满足 |
|--------|----------|------------|
| 质量轴 (m/z) | 仪器质量精度 | 恰好出现在该 m/z |
| 时间轴 (RT) | 色谱重现性 | 恰好出现在该 RT |
| 强度/比例轴 | 检测器响应 | 恰好以预期比例出现 |

干扰要同时通过三轴 → 概率相乘 → 鲁棒性指数级提升。

#### 会同时退化的相关性陷阱

需警惕以下情况，它们让看似独立的维度其实塌成一维：

1. **DIA 窗口加宽**：所有 MS2 端特征同步退化（5Da 失效的核心）
2. **低 S/N**：质量精度、RT 精度、形状精度同时变差
3. **真实共流出肽段**：单一干扰可同时满足 RT、形状、单点 m/z
4. **维度退化为相似度**：当某维度判据从精度比较退化为形状相似度时，独立性丧失

#### 联合检验的数学基础

若 k 个维度近似独立，单个维度随机匹配概率为 p_i，则联合错误概率近似 ∏p_i。

实例：碎片级 Δm 模式特征。N 个碎片的 SILAC 配对，每个被偶然命中的概率约为 ε。所有 N 个同时被偶然命中的概率约为 ε^(2N)（每个碎片需要 light 位置和 heavy 位置都偶然匹配）。N=5、ε=0.1 时，联合概率 ~ 10^-10。

**这正是工具鲁棒性的数学来源：每多一个独立维度，联合假阳性概率乘一个小数。**

## 三、当前状态诊断

### 3.1 2Da 下高 AUC 的真实来源

实测 2Da AUC = 0.968。该数字**并非主要反映特征的鉴别力**。

证据：2Da 数据集中，Decoy 负样本有 70% 的碎片**完全无信号**（`all_p75 == 0`）。

含义：实际起判别作用的判据是"**有无信号**"这一二值现象，而非各 Pearson 特征所宣称的"形状相似度"。Pearson 特征看似 KS 统计量高（如 `y_mean` KS = 0.670），实际是被"无信号 → Pearson 值聚集在 0"这一现象抬高。在"有信号"子集上，Pearson 的真实鉴别力远低于表面数字。

### 3.2 5Da 下的失效根因

5Da 数据集中，Decoy 负样本仅 7.3% 的碎片完全无信号——即 92.7% 的负样本都有真实碎片信号可匹配，这些信号来自共流出的干扰肽段。

所有相似度类特征同步崩塌（KS 从 ~0.67 降到 ~0.17，退化 ~75%）：

| 特征 | 2Da KS | 5Da KS | 退化 |
|------|--------|--------|------|
| `y_mean` | 0.670 | 0.172 | 74%↓ |
| `all_p75` | 0.663 | 0.168 | 75%↓ |
| `all_mean` | 0.666 | 0.161 | 76%↓ |
| `matched_int%` | 0.607 | 0.155 | 74%↓ |
| `precursor_pearson` | 0.125 | 0.131 | 不退化 |

`precursor_pearson` 不退化是因为它基于 MS1 全扫描，不进 DIA 窗口；但它在所有条件下 KS 都很低，本身鉴别力就有限。

**5Da 失效的本质**：相似度判据无法区分"真 SILAC 对"与"真实但身份错误的共流出肽段"。后者也有形状、也有强度——仅靠相似度无法分辨。

### 3.3 已尝试的 `apex_delta` 与 `mz_avg_err` 为何未能挽救

二者都属于视角 B 的单点精度特征，理论上应比相似度特征鲁棒。但实测加入后 5Da AUC 未显著提升。

诊断：**它们击中的是"噪声型干扰"，而非"共流出肽段型干扰"**。

- 共流出肽段就在 RT 附近 → 它的 apex 与 L 的 apex 也接近 → `apex_delta` 也小
- 真实肽段的 m/z 是精确的 → 落在 10ppm 窗口内时同样位于中心附近 → `mz_avg_err` 也小

单点精度特征筛掉了"随机噪声峰"，但筛不掉"真实但身份错误的肽段"。

**结论**：要修这种干扰，需要**序列特异性的多点联合约束**——确保信号不仅在某个位置存在，还**符合 L 序列特有的模式**（如：N 个碎片同时按 K/R 含量正确平移）。

## 四、特征工程路线图

### 4.1 设计原则

每个新增特征必须同时满足：

1. **视角 B**：与 L 的具体预测值对比，而非两个观测信号的相似度
2. **多点联合约束**：构成签名而非单点
3. **退化独立性**：在 5Da 下与现有特征的 KS 退化不同步（即提供新的独立信息）

### 4.2 Priority 1：碎片级 Δm 模式（最强杠杆）

#### 理论基础

L 的 N 个 b/y 离子中，含 K/R 的应平移 Δm，不含的应不平移。这构成 N 位二进制签名，由 L 序列**唯一**决定。

#### 计算流程

```
对每个 PSM L:
  生成 L 的所有理论 b/y 离子（含修饰修正）
  对每个离子 i:
    1. 由该离子的氨基酸组成计算其含 K/R 个数 k_i
    2. 预测 Δm_i = k_i × (heavy_label_mass_diff)
    3. 在 light 位置 mz_L_i 提取 XIC_L_i
    4. 在 heavy 位置 (mz_L_i + Δm_i / charge) 提取 XIC_H_i
    5. 检验该对的配对质量：强度比、形状相关、apex 偏差
```

#### 衍生特征

| 特征名 | 定义 | 真值期望 | 干扰期望 |
|--------|------|---------|---------|
| `frag_pair_count` | 强配对碎片数（满足强度阈值 θ_int 与 Pearson 阈值 θ_corr） | 高 | 低 |
| `frag_pair_ratio` | 强配对数 / 理论碎片数 | 高 | 低 |
| `frag_ratio_mad` | 配对碎片间 log2(I_H/I_L) 的 MAD | 极小 | 大 |
| `frag_shifted_ok_frac` | 预测平移的碎片中实际配对成功的比例 | 高 | 低 |
| `frag_unshifted_clean_frac` | 预测不平移的碎片在 +Δm 位置确实无信号的比例 | 高 | 低 |
| `frag_pattern_loglik` | 观测 Δm 模式与预测模式的对数似然 | 高 | 低 |

> 超参 θ_int、θ_corr 应通过在已知真假数据上扫参标定，配置项放入 `config.ini` 的 `[features.p1]` 段。初始建议：θ_int = light 峰高的 1%，θ_corr = 0.7。

#### 鲁棒性分析

- 干扰肽段 P 要骗过 `frag_pair_ratio`，需要 m 个碎片中相当数量同时：(a) 偶然落在 L 的预测 m/z 上；(b) 在 +Δm 处也偶然有信号
- 联合概率 ~ ε^(2m)。m=5、ε=0.1 时 ~ 10^-10
- `frag_unshifted_clean_frac` 是"陷阱式"特征：不仅检查应有信号的有信号，还检查不应有信号的确实没有——这进一步压缩干扰的成功空间

#### 实现复杂度

中高。需要：

1. 从 L 的序列生成完整的理论 b/y 离子列表（含修饰处理）
2. 对每个离子计算 K/R 含量
3. 重用现有 XIC 提取管线，扩展到碎片级
4. 新增聚合特征
5. 单元测试覆盖：纯 K 肽段、纯 R 肽段、不含 K/R 的肽段、含修饰的边界情况

### 4.3 Priority 2：同位素包络一致性

#### 理论基础

L 的元素组成由其序列+修饰精确决定，可计算理论同位素分布（如使用 averagine 模型或精确同位素计算）。重标候选位置必须满足此预测。

#### 计算流程

```
对每个 PSM L:
  1. 由 L 序列计算理论同位素分布 envelope_pred = [I_M, I_M+1, I_M+2, I_M+3]
  2. 在重标候选 RT 处，对 M、M+1、M+2、M+3 各提取一段 XIC
  3. 取每条 XIC 的峰高（或积分），构成 envelope_obs
  4. 计算 envelope_obs 与 envelope_pred 的偏差度量
```

#### 衍生特征

| 特征名 | 定义 |
|--------|------|
| `iso_envelope_corr` | Pearson(envelope_obs, envelope_pred) |
| `iso_envelope_chi2` | 卡方距离（归一化后） |
| `iso_xic_coherence` | M / M+1 / M+2 三条 XIC 之间的相互 Pearson 均值 |
| `iso_apex_consistency` | 三条 XIC 的 apex 时刻最大偏差 |

#### 鲁棒性分析

- 干扰肽段元素组成不同 → 同位素分布不同。即使 M 通道偶然匹配，M+1 / M+2 比例几乎必然偏离
- 该特征基于 MS1 → 不受 DIA 窗口宽度影响 → 5Da 下不退化

#### 实现复杂度

中。可调用 pyteomics 的同位素计算函数。

### 4.4 Priority 3：跨碎片强度比一致性

#### 理论基础

SILAC 实验中所有真实 SILAC 对应共享同一个混标比（如 1:1）。**跨碎片**的 H/L 比应在小范围内集中。

#### 计算流程

```
对每个 PSM L:
  1. 收集 4.2 中所有成功配对的碎片
  2. 对每对计算 r_i = log2(I_H_i / I_L_i)
  3. 计算 r_i 序列的统计量
```

#### 衍生特征

| 特征名 | 定义 | 真值期望 |
|--------|------|---------|
| `silac_ratio_median` | log2(H/L) 中位数 | ≈ 0（1:1 实验） |
| `silac_ratio_mad` | MAD | 极小 |
| `silac_ratio_iqr` | IQR | 极小 |
| `silac_ratio_outlier_frac` | 偏离 ±1.5×IQR 的碎片占比 | 极小 |
| `silac_ratio_bias` | |中位数 − 实验设定比例| | 极小 |

#### 鲁棒性分析

- 真 SILAC 对：所有碎片受同一混标比驱动 → 比值集中
- 干扰污染：不同碎片受不同强度的干扰 → 比值发散
- 该特征是**多点约束**：单一干扰肽段无法系统性使所有比例同时偏向某固定值

#### 与 Priority 1 的关系

- P1 给"哪些碎片配对成功"
- P3 给"配对成功的碎片是否符合 SILAC 物理"
- 二者级联使用：先 P1 筛选配对，再 P3 验证物理一致性

### 4.5 Priority 4：联合峰形拟合

#### 理论基础

真 SILAC 对来自同一肽段在同一色谱条件下的洗脱，应共享峰形参数（apex μ、峰宽 σ）。可联合拟合一个共享 Gaussian（或 EMG）模型。

#### 计算流程

```
模型 1（共享 apex 和 sigma）:
  XIC_L(t) = A_L · exp(-(t-μ)² / 2σ²)
  XIC_H(t) = A_H · exp(-(t-μ)² / 2σ²)
  拟合参数 (μ, σ, A_L, A_H)，记残差 r1

模型 2（独立 apex，共享 sigma）:
  XIC_L(t) = A_L · exp(-(t-μ_L)² / 2σ²)
  XIC_H(t) = A_H · exp(-(t-μ_H)² / 2σ²)
  拟合参数 (μ_L, μ_H, σ, A_L, A_H)，记残差 r2
```

#### 衍生特征

| 特征名 | 定义 | 真值期望 |
|--------|------|---------|
| `joint_fit_residual` | r1 / (XIC 总能量) | 小 |
| `apex_separation` | \|μ_L − μ_H\|（模型 2 拟合） | 极小 |
| `joint_fit_improvement` | (r1 − r2) / r1 | 极小（共享 apex 已足够） |
| `peak_sigma` | 拟合得到的峰宽 | 在物理合理范围内 |

#### 鲁棒性分析

- 真 SILAC 对：模型 1 已能很好描述 → r1 小，r1 ≈ r2
- 干扰构成的"heavy"：来自不同肽段的峰 → 模型 1 残差大；放开 apex 后（模型 2）apex 分离明显
- 该特征是 Pearson 的强化版：Pearson 只问"形状像不像"，联合拟合问"是不是同一物理过程产生"

#### 实现复杂度

中。使用 scipy.optimize.curve_fit；需处理拟合失败、低 S/N 等边界情况。

### 4.6 Priority 5：多电荷态交叉验证

#### 理论基础

同一肽段在多个电荷态下应同时被观测，且 RT 完全一致。

#### 计算流程

```
对每个 PSM L（鉴定在电荷态 z）:
  对其他电荷态 z' ∈ {z-1, z+1, z+2}（限于合理范围 2~5）:
    1. 计算 light 在 z' 电荷态的 m/z
    2. 在该 m/z 提取 XIC，检查 RT 是否与 z 电荷态一致
    3. 同样检查 heavy 在 z' 电荷态的 m/z
    4. 若 light 和 heavy 在 z' 都存在 → 一次跨电荷态确认
```

#### 衍生特征

| 特征名 | 定义 |
|--------|------|
| `multi_charge_light_count` | light 在多少个电荷态可见 |
| `multi_charge_pair_count` | SILAC 配对在多少个电荷态成立 |
| `multi_charge_rt_mad` | 跨电荷态 RT 的 MAD |

#### 鲁棒性分析

- 独立观测通道。干扰肽段在多个电荷态都骗过的概率 ~ 单电荷概率^k

#### 注意事项

- 并非所有肽段在多个电荷态都强 → 该特征可能缺失
- 需作为"奖励"而非"惩罚"使用（缺失时不参与判别）

### 4.7 五个特征族的预期独立性矩阵

|  | P1 碎片Δm | P2 同位素 | P3 比一致 | P4 联合拟合 | P5 多电荷 |
|--|----|----|----|----|----|
| **P1 碎片Δm** | — | 低相关 | 中相关 | 低相关 | 低相关 |
| **P2 同位素** |  | — | 低相关 | 低相关 | 低相关 |
| **P3 比一致** |  |  | — | 中相关 | 低相关 |
| **P4 联合拟合** |  |  |  | — | 低相关 |

- 实际独立性必须由 §5.2 描述的实验验证，而非仅靠理论分析

## 五、判据形式升级（可选但推荐）

### 5.1 从单一分数到联合 p 值

**当前形式**：30 个特征 → 一个 ML 模型 → 单一分数 → 阈值

**升级形式**：每个独立维度（5 个特征族）→ 独立判别器 → 各自一个统计量 / p 值 → 联合（Fisher 或 Stouffer 方法）→ 联合 p 值

#### 优点

1. **显式编码独立性结构**：联合 p 值的有效性依赖独立性，强制设计者保证独立性
2. **理论意义**：联合 p 值不依赖 TDA 校准，可作为独立的可信度估计
3. **可解释性**：每个 PSM 的拒绝可追溯到具体维度——可以说"该 PSM 在 P1/P3 维度未通过"

#### 实施路径

1. 对每个特征族 Pᵢ 训练独立判别器，输出该族的鉴别分数 sᵢ
2. 在已知负样本上估计每个分数的零分布 → 转化为 p 值 pᵢ
3. 用 Fisher's combined probability test 合并：χ² = -2 Σ ln(pᵢ)，df = 2k
4. 校准检验：在已知真假数据集上检验联合 p 值是否近均匀分布

### 5.2 各维度独立性验证

独立性是联合检验的前提，必须通过实验验证而非仅靠理论分析。验证方法：

1. **相关性矩阵**：在大规模 PSM 上计算各特征族输出之间的 Spearman 相关
2. **退化同步性测试**：检查 2Da → 5Da 退化幅度的相关——同步退化 = 存在共同失败机制
3. **条件独立性检验**：在已知正样本子集和已知负样本子集分别检查独立性
4. **置换检验**：随机打乱某一特征族的 PSM 标签，检查联合判别器性能下降——下降应小于该族独立 KS 的暗示水平

## 六、验证协议

### 6.1 性能目标

| 数据集 | 当前 AUC | 目标 AUC |
|--------|---------|---------|
| 2Da only | 0.968 | 维持 ≥ 0.96 |
| 2Da + 5Da 混合 | 0.838 | ≥ 0.90 |
| 5Da only | 0.659 | ≥ 0.85 |

附加关注：

- **5Da 负样本召回**（当前 ≈ 0%）应达 ≥ 50%
- **5Da 负样本精确**应达 ≥ 80%
- **训练-测试无泄漏**：所有 AUC 在 Rep1+2 训练、Rep3 测试的设置下报告

### 6.2 与 TDA 的对照实验

**实验设置**：

1. 在标准 entrapment 数据集上同时运行 TDA 和 SILAC-validation
2. 将 PSM 分类为四类：
   - TDA 通过 & SILAC 通过 → 高置信
   - TDA 拒绝 & SILAC 拒绝 → 一致拒绝
   - TDA 通过 & SILAC 拒绝 → **TDA 可能高估**（重点分析）
   - TDA 拒绝 & SILAC 通过 → **TDA 可能误杀**（重点分析）
3. 对不一致案例做半自动验证（人工核查 + 物理特征汇总），统计 TDA 与 SILAC 哪一方更接近真值
4. 按肽段长度、修饰类型、电荷态、搜索引擎种类分桶，研究系统性偏差

**核心论文贡献候选**：

- 是否存在系统性的 TDA 失效模式？（按肽段类型分桶的失效率统计）
- 当 SILAC-validation 与 TDA 不一致时，哪些特征族提供了关键的反驳证据？
- SILAC-validation 在哪些场景下也会失效？（见 §6.3）

### 6.3 失败模式刻画

预计 SILAC-validation 在以下条件失败，需要系统量化：

| 失败条件 | 机制 | 量化方法 |
|---------|------|---------|
| 真共流出且巧合配对 | 另一肽段恰好满足所有维度 | 在已知真假数据上分析 false negative 的物理特征 |
| 低强度重标 | H 信号低于检测限 → 所有维度退化 | 按 light intensity 分箱，绘制 AUC vs intensity 曲线 |
| 修饰肽段 | 修饰可能改变 K/R 数 | 比较修饰 vs 非修饰肽段的 AUC |
| 极宽窗（≥ 25Da MSE/SWATH） | MS2 端干扰极重 | 模拟扩窗实验（如有数据）或人工干扰注入 |
| 短肽段 | 碎片数太少 → P1 失效 | 按肽段长度分箱的 AUC |

每种失败模式需给出：

1. 数据集构造方式（人工注入或筛选）
2. AUC 退化量化
3. 该条件下特征族独立性是否依然成立

## 八、风险与开放问题

### 8.1 已识别风险

1. **Priority 1 实现复杂度高**：碎片级 XIC 提取的工程量大，需要小心设计以保证性能（当前管线已优化前体级 XIC，扩展到 ~10× 碎片需评估内存/时间影响）
2. **理论同位素分布的不确定性**：averagine 模型在非典型氨基酸组成下有偏差；可能需要精确元素组成计算
3. **独立性可能在某些场景下被打破**：例如低 S/N 下所有维度同时退化，联合 p 值会高估可信度
4. **目标 AUC 可能过于乐观**：5Da AUC 从 0.659 到 0.85 是大跨度提升，需要预留计划备选

### 8.2 开放问题

1. **如何定义"通过 SILAC-validation"的阈值？** 是用固定 p 值阈值，还是按 FDR 控制？
2. **是否应支持非 1:1 的 SILAC 实验？** 当前设计假设 1:1，对其他比例需要参数化
3. **跨 raw file 的证据是否应汇总？** 同一肽段在 9 个 raw file 中可能多次出现，每次独立验证 vs 联合验证的权衡
4. **是否应回流到搜索引擎？** SILAC-validation 的结果能否反过来改进搜索引擎的评分？
