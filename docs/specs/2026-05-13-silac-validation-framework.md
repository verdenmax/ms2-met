## 一、研究背景与定位

### 1.1 问题陈述

蛋白质组学搜索引擎（DIA-NN、AlphaDIA 等）通过将实验谱图与理论谱图匹配来鉴定肽段。目前主流的质量控制方法是 **Target-Decoy Approach (TDA)**：在数据库中加入反向（decoy）序列，通过搜索结果中 decoy 的比例估算 False Discovery Rate (FDR)。

TDA 存在以下结构性局限：

1. **假设依赖**：TDA 假设 decoy 与 target 在干扰分布上等价。该假设在 DIA 宽窗口、稀有修饰、非典型肽段等场景下可能失效。
2. **盲点**：TDA 给出全局 FDR 估计，**无法标识具体哪些 PSM 是错的**——它只能说"这一批里有 1% 是错的"，不能指出是哪一条。
3. **缺乏独立性**：TDA 与搜索引擎使用同一套谱图证据（谱匹配），没有真正的外部验证。

### 1.2 本工具的定位

**ms2-met 是 TDA 的独立第二意见**——对搜索引擎已鉴定的每一条轻标 PSM，基于一种与谱匹配机制无关的物理证据（SILAC 配对），独立判断其可信度。

具体而言：利用 SILAC 标记实验中"轻标和重标必须成对出现且具有可预测物理关系"这一事实，对搜索引擎给出的每条轻标鉴定，去原始数据中寻找重标证据。若证据充分 → 鉴定可信；若证据缺失 → 鉴定可疑。

### 1.3 核心论点

> **对于已鉴定的轻标 PSM，我们由其序列推导出对重标信号的多维联合预测，并在数据中检验这些预测是否被独立证据同时满足。**

该论点的关键性质：

- **独立性**：SILAC 配对所依赖的物理事实（轻重标的化学等价性导致的 RT/形状/比例一致）与搜索引擎的谱匹配机制完全独立。
- **多维**：质量、时间、强度、形状、序列等多个测量维度构成联合约束。
- **可校准**：每个维度都有明确的预测值与实测值的偏差度量，可给出基于物理的、不依赖 decoy 的置信度。

### 1.4 与 TDA 的互补关系

| 维度 | TDA | SILAC-validation |
|------|-----|------------------|
| 证据来源 | decoy 分布 | 物理预测 vs 实测 |
| 校准类型 | 全局 FDR | 单 PSM 置信度 |
| 关键假设 | decoy 代表 target 的干扰分布 | 轻重标化学等价 |
| 主要失败模式 | decoy 分布偏离时校准失效 | 真实共流出肽段恰好同时满足全部预测 |
| 适用域 | 大规模筛选 | 关键鉴定的独立验证 / TDA 校准检查 |

二者是**正交互补**的关系。当二者结论一致 → 高置信；当二者结论不一致 → 高信息量的研究案例，可用于发现搜索引擎或 TDA 的系统性问题。

### 1.5 方法论澄清：为什么"用 L 的预测验证 L"不是循环逻辑

本工具最容易被质疑的一点是：

> "L 是搜索引擎从数据中鉴定出来的。如果 L 错了，L 的预测也跟着错。再用一个错的预测去检验数据，能说明什么？"

本节系统澄清此疑问。

#### 1.5.1 用于"鉴定 L"的数据与用于"验证 L"的数据在测量上独立

虽然两份数据来自同一次实验、同一个色谱柱、同一台仪器，但它们对应**不同的 m/z 区域和不同的 MS2 扫描循环**：

| 数据角色 | 谱图来源 | 用途 |
|---------|---------|------|
| 鉴定数据 | Light 前体的 MS1 信号 + 其触发的 MS2 谱图 | 搜索引擎用以鉴定 L |
| **验证数据** | **Heavy 前体的 MS1 信号 + 其触发的 MS2 谱图** | **本工具用以验证 L** |

关键事实：

- **重标谱图从未参与 L 的鉴定**。搜索引擎只看 light 数据，给出 L。
- 本工具用 L 推出"如果 L 是对的，重标数据应当呈现的样子"，然后去**完全独立的重标数据**中检查。
- 二者通过物理规律（Δm 差、化学等价性）关联，但在测量层面是独立的——不同的 m/z 区域、不同的扫描循环、可能不同的 DIA 窗口。

因此不存在"用同一份数据既鉴定又验证"的循环。

#### 1.5.2 这是经典的假设-预测-验证范式

本工具的逻辑链条：

```
1. 搜索引擎给出 L（不论对错）
2. 由 L 的序列推导"如果 L 为真，重标数据应当呈现的可观测属性"
3. 在独立的重标数据中检验这些属性
4. 根据满足程度作出关于 L 的判断
```

这是科学方法的标准范式：**提出假设 → 推出可观测预测 → 用独立数据检验**。L 是"待检验假设"，不是"已被默认为真的前提"。L 是否正确，正是被这套机制**判定**出来的。

#### 1.5.3 L 错时联合预测被满足的概率极低

考察 L 错时的三种典型情形：

**情形 A：L 错且重标位置完全无信号**

各维度全部失败 → 拒绝 L。这是稀疏数据（2Da 窗口）下的主要情形，占负样本的 60-70%。

**情形 B：L 错但 m/z 窗口内存在真实共流出肽段**

- 部分维度（m/z 单点、RT、形状相似度）被欺骗 → 单维度判据失效
- **但**：该干扰肽段的元素组成与 L 不同 → 同位素包络不符；其碎片 b/y 模式由其自身序列决定 → 不会按 L 的 K/R 模式平移
- 多维度判据（同位素包络一致性、碎片 Δm 模式、跨碎片比一致性）仍能拒绝 L
- 这是 5Da 窗口下的主要情形，也是单维度方法失效（5Da AUC 0.659）、多维度方法可挽救的全部数学根据

**情形 C：L 错但所有维度恰好同时被欺骗**

联合概率约为 ∏ᵢ pᵢ。当独立维度数 ≥ 5 且每维度被偶然满足概率 ≤ 0.3 时，联合概率 ≤ 0.3⁵ ≈ 0.002。实际系统中可达 10⁻⁸ 量级（参见 §2.3）。这是工具的固有 false-positive 上限。

#### 1.5.4 检验的统计意义

检验的强度**不取决于"L 是否提前被假设为真"**，而取决于"L 错时联合预测被偶然满足的概率"。后者越低，检验越强。

类比：如果某人声称能预测彩票号码，验证其声称是否成立——不是"循环验证"——而是看"如果他在瞎说，所有号码同时被偶然命中"的概率有多低。概率越低，命中事件越是关于"他是否真有预测能力"的强证据。

#### 1.5.5 与"重标位置有无信号"这种最简版本的区别

最简版本（仅检查重标位置是否有信号）也属于本框架，但是单维度版本。它在 5Da 下被穿透（情形 B 大量发生）。本框架的核心贡献正是将"重标位置是否符合预测"细化为多个独立维度的联合检验，使情形 B 也能被识别。

#### 1.5.6 一句话总结

> **L 的预测不是"先假设 L 对"的产物，而是"如果 L 对应该看到什么"的可证伪声明。**
>
> **数据满不满足这些声明，正是判断 L 是否对的依据。多维独立预测的联合验证，让"L 错但全部碰巧满足"的概率指数级降低——这就是工具检验意义的全部数学来源。**

## 二、理论框架

### 2.1 视角 A vs 视角 B——判据形式的根本区别

任何特征的本质都可归入两类形式之一：

**视角 A（相似度判据）**

- 形式：`feature(observed_light, observed_heavy_candidate) → similarity_score`
- 本质：对称地比较两个观测信号的相似度
- 典型例子：`Pearson(light_xic, heavy_xic)`
- 弱点：任何形状相似的真实信号都能通过——包括无关肽段

**视角 B（精度判据）**

- 形式：`feature(observed, L's_prediction) → deviation`
- 本质：度量实测信号偏离 L 预测的程度
- 典型例子：`mz_avg_err = |observed_mz - L_predicted_mz| / predicted_mz` (ppm)
- 强点：L 的预测值直接进入判据，干扰必须精确命中预测位置才能通过

**核心原则**：每个特征设计时都应能回答以下问题：

1. L 在这个维度上的预测值是什么？（一个具体的数）
2. 我的特征是不是在度量实测值与该预测值的偏差？
3. 如果是 → 视角 B；如果只是在比较两个观测信号的相似度 → 视角 A。

### 2.2 L 对 H 的完整预测——按物理量分类

L 对其重标对应物 H 的预测可按测量轴分为 5 类：

**类 1：质量轴预测**

- **前体 m/z**：每个电荷态一个精确值，由 L 序列和 SILAC 标记的 Δm 决定
- **同位素包络**：M、M+1、M+2、M+3... 的相对强度，由肽段元素组成精确预测
- **碎片 m/z**：每个 b/y 离子是否平移 Δm，取决于该离子是否包含 K/R 残基——这构成一个序列特异的位掩码模式

**类 2：时间轴预测**

- **保留时间**：RT_H ≈ RT_L（理论上化学等价，偏差仅来自微小同位素效应）
- **峰宽**：相同色谱条件下相近
- **Apex 时刻**：apex_H ≈ apex_L

**类 3：形状轴预测**

- **前体 XIC 形状**：H 的前体 XIC 与 L 的前体 XIC 高度共流出
- **碎片 XIC 形状**：每个碎片各自有自己的 XIC，都应与 L 对应碎片共流出

**类 4：强度轴预测**

- **L:H 总强度比**：由样本混标比决定（如 1:1）
- **跨碎片强度比一致性**：所有成功配对的碎片应共享同一个 H/L 比例
- **电荷态分布**：H 应在 L 出现的所有电荷态都可见

**类 5：序列签名预测**（最强但最被忽视）

- **碎片 Δm 模式**：L 的 N 个 b/y 离子中，哪些应平移、哪些不应——构成 N 位二进制签名
- **同位素峰间距模式**：1.00335 Da 等差数列
- **多电荷态共存模式**：跨电荷态 RT 一致

### 2.3 独立性结构

#### 真正独立的三条物理轴

| 物理轴 | 噪声来源 | 干扰需满足 |
|--------|----------|------------|
| 质量轴 (m/z) | 仪器质量精度 | 恰好出现在该 m/z |
| 时间轴 (RT) | 色谱重现性 | 恰好出现在该 RT |
| 强度/比例轴 | 检测器响应 | 恰好以预期比例出现 |

干扰要同时通过三轴 → 概率相乘 → 鲁棒性指数级提升。

#### 会同时退化的相关性陷阱

需警惕以下情况，它们让看似独立的维度其实塌成一维：

1. **DIA 窗口加宽**：所有 MS2 端特征同步退化（5Da 失效的核心）
2. **低 S/N**：质量精度、RT 精度、形状精度同时变差
3. **真实共流出肽段**：单一干扰可同时满足 RT、形状、单点 m/z
4. **维度退化为相似度**：当某维度判据从精度比较退化为形状相似度时，独立性丧失

#### 联合检验的数学基础

若 k 个维度近似独立，单个维度随机匹配概率为 p_i，则联合错误概率近似 ∏p_i。

实例：Q1a 平移碎片 SILAC 配对率。N 个含 K/R 的理论碎片中，每个被偶然命中（light 位置 + heavy 位置都偶然有信号且共流出）的概率约为 ε。N 个同时被偶然命中的概率约为 ε^N。N=5、ε=0.1 时联合概率 ~ 10⁻⁵；若加上 Q1b 的不平移碎片陷阱位置的独立检查（每个陷阱位置偶然干净的概率较高，但其作为补充约束依然提供一些独立信息），整体联合错误率进一步降低。

**这正是工具鲁棒性的数学来源：每多一个独立维度，联合假阳性概率乘一个小数。**

## 三、当前状态诊断

### 3.1 2Da 下高 AUC 的真实来源

实测 2Da AUC = 0.968。该数字**并非主要反映特征的鉴别力**。

证据：2Da 数据集中，Decoy 负样本有 70% 的碎片**完全无信号**（`all_p75 == 0`）。

含义：实际起判别作用的判据是"**有无信号**"这一二值现象，而非各 Pearson 特征所宣称的"形状相似度"。Pearson 特征看似 KS 统计量高（如 `y_mean` KS = 0.670），实际是被"无信号 → Pearson 值聚集在 0"这一现象抬高。在"有信号"子集上，Pearson 的真实鉴别力远低于表面数字。

### 3.2 5Da 下的失效根因

5Da 数据集中，Decoy 负样本仅 7.3% 的碎片完全无信号——即 92.7% 的负样本都有真实碎片信号可匹配，这些信号来自共流出的干扰肽段。

所有相似度类特征同步崩塌（KS 从 ~0.67 降到 ~0.17，退化 ~75%）：

| 特征 | 2Da KS | 5Da KS | 退化 |
|------|--------|--------|------|
| `y_mean` | 0.670 | 0.172 | 74%↓ |
| `all_p75` | 0.663 | 0.168 | 75%↓ |
| `all_mean` | 0.666 | 0.161 | 76%↓ |
| `matched_int%` | 0.607 | 0.155 | 74%↓ |
| `precursor_pearson` | 0.125 | 0.131 | 不退化 |

`precursor_pearson` 不退化是因为它基于 MS1 全扫描，不进 DIA 窗口；但它在所有条件下 KS 都很低，本身鉴别力就有限。

**5Da 失效的本质**：相似度判据无法区分"真 SILAC 对"与"真实但身份错误的共流出肽段"。后者也有形状、也有强度——仅靠相似度无法分辨。

### 3.3 已尝试的 `apex_delta` 与 `mz_avg_err` 为何未能挽救

二者都属于视角 B 的单点精度特征，理论上应比相似度特征鲁棒。但实测加入后 5Da AUC 未显著提升。

诊断：**它们击中的是"噪声型干扰"，而非"共流出肽段型干扰"**。

- 共流出肽段就在 RT 附近 → 它的 apex 与 L 的 apex 也接近 → `apex_delta` 也小
- 真实肽段的 m/z 是精确的 → 落在 10ppm 窗口内时同样位于中心附近 → `mz_avg_err` 也小

单点精度特征筛掉了"随机噪声峰"，但筛不掉"真实但身份错误的肽段"。

**结论**：要修这种干扰，需要**序列特异性的多点联合约束**——确保信号不仅在某个位置存在，还**符合 L 序列特有的模式**（如：N 个碎片同时按 K/R 含量正确平移）。

### 3.4 5Da 下的结构性现象——L 与 H 的 DIA 窗口共选

考察 5Da 数据集的另一个被忽视的物理事实：**L 和 H 在 DIA 隔离窗口中大概率被同时选中**。

K8R10 标记下 L 与 H 的前体 m/z 差为 Δm/z：

| 电荷态 z | K8 时 Δm/z | R10 时 Δm/z | 5Da 窗口下共选 |
|---------|-----------|-------------|---------------|
| z=2 | 4.0 Da | 5.0 Da | 部分（边界依赖） |
| z=3 | 2.67 Da | 3.33 Da | **大概率** |
| z=4 | 2.0 Da | 2.5 Da | **几乎必然** |

在 z≥3 的 PSM 中（占 5Da 数据集大部分），L 和 H 同时被隔离、同时被碎裂，**它们的碎片出现在同一张 MS2 谱图中**。

#### 共窗口 vs 分窗口——对碎片可分离性的根本影响

碎片的 light 信号源（来自 L）与 heavy 信号源（来自 H）是否可独立测量，取决于两个维度的分离：

| 碎片类型 | m/z 是否分离 | DIA 窗口扫描是否分离（依共/分窗口） |
|---------|-------------|-----------------------------------|
| 平移碎片（含 K/R） | **是**（不同 m/z） | 视情形 |
| 不平移碎片（不含 K/R） | **否**（同 m/z） | 视情形 |

组合结果：

| 情形 | 平移碎片 | 不平移碎片 |
|------|----------|-----------|
| **共窗口**（W_L = W_H） | ✓ 可分离（m/z 分离） | ✗ 不可分离（同扫描、同 m/z，物理叠加） |
| **分窗口**（W_L ≠ W_H） | ✓ 可分离（m/z 分离） | ✓ 可分离（窗口分离：相同 m/z 但取自不同窗口扫描） |

#### 关键推论

1. **共窗口下，仅平移碎片可参与 SILAC 配对验证**——不平移碎片的 L 与 H 信号叠加于同一谱图同一 m/z，无法独立分辨。
2. **分窗口下，平移和不平移碎片均可参与配对验证**——通过 `xic_ms2_peaks_extract(precursor_mz=mz_L_或_mz_H, ions_mass=...)` 按窗口分离提取，获得独立的 light 和 heavy 信号。
3. 因此 Q1a（SILAC 配对率）的有效碎片集合**动态依赖于 W_L 与 W_H 的关系**，由 §4.7 的 W1 特征控制。
4. **分窗口下 Q1a 鉴别力反而更强**——可用独立证据更多（同时利用 m/z 分离和窗口分离两类机制），联合假阳性概率指数级降低。共窗口虽然共流出完美，但可用碎片数减半。
5. 上述区分体现在 §4.2 的 Q1a（可分离碎片配对）与 Q1b（不平移碎片陷阱干净度）的子族拆分中。

该结构性现象不仅是失败诊断的关键，也是分窗口下额外检测机会的来源（详见 §4.2 拆分特征与 §4.7 W1）。

## 四、特征工程路线图

### 4.1 设计原则

每个新增特征必须同时满足：

1. **视角 B**：与 L 的具体预测值对比，而非两个观测信号的相似度
2. **多点联合约束**：构成签名而非单点
3. **退化独立性**：在 5Da 下与现有特征的 KS 退化不同步（即提供新的独立信息）

### 4.2 Priority 1：碎片级 Δm 模式（最强杠杆）

#### 理论基础

L 的 N 个 b/y 离子中，含 K/R 的应平移 Δm，不含的应不平移。这构成 N 位二进制签名。

**但两类碎片提供的证据本质不同，必须独立分析**：

| 碎片类型 | light vs heavy 位置 | 共窗口可分辨性 | 分窗口可分辨性 |
|---------|---------------------|--------------|--------------|
| **平移碎片**（含 K/R） | 不同 m/z | ✓ 可分辨（m/z 分离） | ✓ 可分辨（m/z + 窗口分离） |
| **不平移碎片**（不含 K/R） | 同 m/z（mz_L = mz_H） | ✗ 不可分辨（同扫描叠加） | ✓ 可分辨（窗口分离） |

**核心标准**：light 与 heavy 信号源在 m/z 或 DIA 窗口扫描上**至少一维分离**。

依此标准：

- 共窗口下：**仅平移碎片可参与 SILAC 配对验证**
- 分窗口下：**所有碎片均可参与**——通过给 `xic_ms2_peaks_extract` 传不同的 precursor_mz 来自动按窗口分离提取

因此 Priority 1 拆分为两个独立子族：

- **Q1a**：可分离碎片的 SILAC 配对率——核心 SILAC 验证证据（动态依赖 W_L 与 W_H 关系）
- **Q1b**：不平移碎片的陷阱位置干净度——独立的负向证据（与窗口关系无关）

#### Q1a：可分离碎片 SILAC 配对率（核心）

##### 可分离性判定

每个理论 b/y 离子 i 是否参与 Q1a，由 `is_separable(i)` 决定：

```
def is_separable(fragment_i, W_L, W_H):
    if (n_K_i + n_R_i) > 0:      # 平移碎片
        return True              # m/z 分离，始终可分离
    else:                        # 不平移碎片
        return W_L != W_H        # 仅分窗口下可分离
```

##### 计算流程

```
对每个可分离的理论 b/y 离子 i:
    # 由 i 自身的 K/R 数计算预测的 m/z 平移
    Δm_i = (n_K_i × Δ_K + n_R_i × Δ_R) / z_frag_i

    # XIC 提取——分别用 L 和 H 的母离子 m/z 选择 DIA 窗口
    XIC_L = extract(precursor_mz=mz_prec_L, ions_mass=mz_frag_L_i)
    XIC_H = extract(precursor_mz=mz_prec_H, ions_mass=mz_frag_L_i + Δm_i)

    # 显著性判定（三条件：强度、共流出、峰形）
    light_present = 三条件判定(XIC_L)
    heavy_present = 三条件判定(XIC_H)

    if light_present AND heavy_present:  state = TP
    elif light_present AND NOT heavy_present:  state = FN
    else:  不参与统计（light 信号无法确认）
```

**注意**：对于不平移碎片在分窗口情形下，Δm_i = 0、mz_frag_L = mz_frag_H，但 precursor_mz 不同 → 由 `xic_ms2_peaks_extract` 自动从对应 DIA 窗口扫描提取，得到分离的 light 和 heavy 信号。

##### 衍生特征

**主特征**：

| 特征名 | 公式 | 含义 |
|--------|------|------|
| `q1a_TP_count` | 全部 TP 数 | 配对成功的可分离碎片数 |
| `q1a_FN_count` | 全部 FN 数 | 缺重标的可分离碎片数 |
| `q1a_recall` | TP / (TP + FN) | **核心特征**：可分离碎片的 SILAC 配对率 |
| `q1a_total_count` | TP + FN | 有效可分离碎片数（< 3 视为 q1a_valid = False） |

**按分离机制拆分**（用于诊断与独立性分析）：

| 特征名 | 适用碎片 | 何时非零 | 说明 |
|--------|---------|---------|------|
| `q1a_TP_shifted` | 含 K/R 平移碎片 | 所有 PSM | m/z 分离的 SILAC 配对 |
| `q1a_FN_shifted` | 含 K/R 平移碎片 | 所有 PSM | |
| `q1a_recall_shifted` | TP_shifted / (TP_shifted + FN_shifted) | 所有 PSM | 经典 SILAC 配对率，与窗口无关 |
| `q1a_TP_unshifted_separable` | 不含 K/R 但可分离的碎片 | **仅分窗口** | 窗口分离的 SILAC 配对 |
| `q1a_FN_unshifted_separable` | 同上 | **仅分窗口** | |
| `q1a_recall_unshifted_separable` | TP_uns / (TP_uns + FN_uns) | **仅分窗口** | 共窗口下为 NaN |

拆分的价值：两类配对被欺骗的物理机制不同（一个由 m/z 分离保护，另一个由窗口分离保护），近似独立。模型可分别学习权重；联合 p 值时它们提供独立维度。

**离子类型细分**：

| 特征名 | 计算范围 | 说明 |
|--------|---------|------|
| `q1a_y_recall` | 所有可分离碎片中的 y 离子 | y 全平移定律（胰蛋白酶产物期望 → 1） |
| `q1a_b_recall` | 所有可分离碎片中的 b 离子 | b 离子配对率 |
| `q1a_y_count` | y 离子 TP 数 | |
| `q1a_b_count` | b 离子 TP 数 | |

##### 真值期望

- `q1a_recall` → 1.0
- `q1a_recall_shifted` → 1.0
- `q1a_recall_unshifted_separable` → 1.0（分窗口下）或 NaN（共窗口下）
- `q1a_y_recall` → 1.0（胰蛋白酶产物的强约束）

##### 鉴别力来源

每个 TP 是一次独立的"L 序列预测正确"的物理验证。N 个 TP 中只要发生几次 FN，就是 L 错的强迹象。

**共窗口情形**（仅平移碎片参与）：
- 干扰肽段 P 要骗过 q1a_recall：P 的多个 b/y 同时落在 L 的预测平移位置（不同 m/z 上）
- 概率 ~ ε^N_shifted。N_shifted ≈ 5 时 ~ 10⁻⁵

**分窗口情形**（平移 + 不平移可分离碎片均参与）：
- 需 N_shifted 个平移碎片正确 + N_unshifted 个不平移碎片在 W_H 窗口扫描中也共流出
- 独立维度更多 → 联合假阳性概率更低
- N_shifted + N_unshifted ≈ 10 时 ~ 10⁻¹⁰

**分窗口下 Q1a 鉴别力反而更强**——尽管共流出度不如共窗口完美，但可用独立证据数显著增加。

##### 共窗口与分窗口的角色

- 共窗口：可用证据少（仅平移碎片），但共流出严格（W2/W4 可用更严格阈值，详见 §4.7）
- 分窗口：可用证据多（含不平移碎片的窗口分离配对），共流出略宽松
- 二者各有优势，应由 W1 特征显式编码情形供模型学习

#### Q1b：不平移碎片陷阱位置干净度（负向证据）

##### 计算流程

**第一阶段简化**：仅从 W_L 窗口扫描查陷阱位置（即 `precursor_mz = mz_prec_L`）。覆盖 PSM 主要的干扰来源。

```
对每个不含 K/R 的理论 b/y 离子 j:
    # 第一步：确认 light 位置有信号（共窗口下天然成立，仅作为参与统计的入门条件）
    XIC_L_j = extract(precursor_mz=mz_prec_L, ions_mass=mz_b_j)
    if NOT 三条件判定(XIC_L_j): 跳过该碎片

    # 第二步：对两个陷阱位置（+Δ_K, +Δ_R）独立检测
    for shift in [Δ_K, Δ_R]:
        trap_mz = mz_b_j + shift / z_b_j

        # 撞车排除：陷阱位置不能与 L 的任何其他理论离子 m/z 接近
        if 存在某 L 理论离子 i' 使得 |mz_i' - trap_mz| < q1b_collision_tol_ppm × trap_mz:
            跳过该陷阱位置

        XIC_trap = extract(precursor_mz=mz_prec_L, ions_mass=trap_mz)
        trap_present = 三条件判定(XIC_trap)

        if trap_present:  state = FP（陷阱命中），按 shift 类型记录到 K 或 R 子集
        else:  state = TN（陷阱干净）
```

**第二阶段扩展**（未来）：分窗口下额外用 `precursor_mz=mz_prec_H` 在 W_H 中查同一陷阱位置——提供"L 周围"与"H 周围"两个独立的干扰密度视角。

##### 衍生特征

**主特征**：

| 特征名 | 公式 | 含义 |
|--------|------|------|
| `q1b_TN_count` | TN 数 | 干净陷阱位置数 |
| `q1b_FP_count` | FP 数 | 命中陷阱位置数 |
| `q1b_specificity_unshifted` | TN / (TN + FP) | **核心特征**：陷阱位置干净度 |
| `q1b_FP_rate` | FP / (TN + FP) | 陷阱命中率（与 specificity 互补） |
| `q1b_total_traps` | TN + FP | 有效陷阱位置数（< 3 视为 q1b_valid = False） |

**按陷阱类型拆分**（K vs R 漏算诊断）：

| 特征名 | 计算范围 | 说明 |
|--------|---------|------|
| `q1b_TN_count_K` / `q1b_FP_count_K` / `q1b_specificity_K` | 仅 +Δ_K 陷阱 | "K 陷阱"干净度——漏算 K 时此值显著低于 R 陷阱 |
| `q1b_TN_count_R` / `q1b_FP_count_R` / `q1b_specificity_R` | 仅 +Δ_R 陷阱 | "R 陷阱"干净度——漏算 R 时此值显著低于 K 陷阱 |

**强度类软分**（区分弱干扰与强污染）：

| 特征名 | 公式 | 含义 |
|--------|------|------|
| `q1b_max_FP_intensity_ratio` | max(I_trap_hit / I_light_b_at_same_position)，限于 FP | 最强陷阱命中的相对强度 |
| `q1b_mean_FP_intensity_ratio` | mean(...)，限于 FP | 平均陷阱命中相对强度 |

强度类特征仅在 FP_count > 0 时有意义；FP_count = 0 时为 NaN。

##### 超参

| 超参 | 默认值 | 含义 |
|------|--------|------|
| `q1b_collision_tol_ppm` | 10 ppm | 陷阱位置与 L 其他理论离子的撞车排除阈值 |

其他超参（`ppm_tol`, `xic_window`, `coflow_tolerance`, `noise_factor`, `min_peak_cycles`）与 Q1a 共享。

##### 真值期望

- `q1b_specificity_unshifted` → 1.0（绝大多数陷阱位置干净）
- `q1b_specificity_K` 与 `q1b_specificity_R` 应**对称**接近 1.0（不对称暗示特定残基漏算）
- `q1b_max_FP_intensity_ratio` 小（FP 通常是弱 isobaric 残留）

##### 鉴别力来源

Q1b 提供**独立于 Q1a 的负向证据**：

- **环境密度评估**：specificity 低 = PSM 周围 m/z 空间挤满干扰 → 提示其他特征的 TP 可能被高估，整体可信度下降
- **K vs R 漏算诊断**：specificity_K 与 specificity_R 的不对称是 L 漏算特定残基的信号
- **作为 Q1a 的置信度调节器**：q1b 干净 → 信赖 Q1a；q1b 脏 → Q1a 结果需打折

需注意：q1b 的鉴别力**没有 Q1a 强**，主要价值是辅助评估而非独立判定。

##### 重要警告

不平移碎片的 light 位置存在性**不构成 L 对的独立证据**——它在共窗口下天然成立，且搜索引擎已经用过这个证据。因此 Q1b **不**输出 "light 存在数" 类特征。

##### 与 Q1a 的联合解读

| Q1a recall | Q1b specificity | 综合解读 |
|-----------|----------------|---------|
| 高 | 高 | **强支持 L** |
| 高 | 低 | Q1a 可能被环境干扰高估（谨慎） |
| 低 | 高 | Q1a 暗示 L 错（环境干净，结论可信） |
| 低 | 低 | 整体可疑（可能 L 错 + 环境差） |

这是"q1_MCC 不作为单值综合度量"的根本原因——两个子族提供**正交信息**，应交由模型独立学习权重。

#### Q1 综合特征（弱，不作为主特征）

| 特征名 | 公式 | 说明 |
|--------|------|------|
| `q1_MCC` | $\frac{TP \cdot TN - FP \cdot FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}$ | Matthews 相关系数，综合四种状态 |

**重要警告**：q1_MCC 在共窗口下可能**虚假抬高**——TN 几乎天然存在（陷阱位置本就极少有干扰），把 MCC 拉高的可能不是 L 的真鉴别力。因此 **q1_MCC 不应作为主特征**，仅作为可解释性的辅助分数。

**主特征是 q1a_recall_shifted 和 q1b_specificity_unshifted**——它们物理意义清晰、独立性强，让模型独立学习二者的权重。

#### 信号显著性判定（三条件）

对任一位置的 XIC，"显著存在"必须同时满足：

1. **绝对强度**：max(XIC) > 5 × MS2 本底噪声
2. **共流出**：apex(XIC) 与 light apex 偏差 ≤ ±N cycle
3. **峰形**：FWHM > 最小 cycle 数（排除单点噪声）

#### 超参

| 超参 | 默认值 | 含义 |
|------|--------|------|
| `ppm_tol` | 10 ppm | 质量容忍（沿用 mass_tol_ppm） |
| `xic_window` | ±6 cycle | RT 窗口（沿用 xic_cycle_window） |
| `coflow_tolerance` | ±3 cycle | 信号显著性中"共流出"的严格程度 |
| `noise_factor` | 5.0 | 信号显著性中"绝对强度"的噪声倍数 |
| `min_peak_cycles` | 2 | 信号显著性中"峰形"的 cycle 下限 |
| `q1b_collision_tol_ppm` | 10 ppm | 陷阱位置与 L 其他理论离子的撞车排除阈值 |

超参应通过在已知真假数据上扫参标定，配置项放入 `config.ini` 的 `[features.q1]` 段。

#### 鲁棒性分析

- **Q1a 的干扰免疫**：干扰肽段 P 要骗过 q1a_recall_shifted，需要 P 的多个碎片同时落在 L 的预测平移位置——这要求 P 的 K/R 分布与 L 一致（极小概率，~ ε^N）
- **Q1b 的局限**：陷阱位置只检测"位置有无干扰信号"，对 L-错本身的鉴别力弱于 Q1a
- 二者**独立**：Q1a 测平移碎片的正面证据，Q1b 测不平移碎片的负面证据，物理来源不同

#### 实现复杂度

中高。需要：

1. 从 L 的序列生成完整的理论 b/y 离子列表（含修饰处理）
2. 对每个离子计算 K/R 含量并分类（平移 / 不平移）
3. 重用现有 XIC 提取管线，扩展到碎片级
4. Q1b 需要额外的"撞车排除"逻辑（计算陷阱位置与 L 其他理论离子的最小距离）
5. 单元测试覆盖：纯 K 肽段、纯 R 肽段、不含 K/R 的肽段、含修饰的边界情况、陷阱位置撞车场景


### 4.3 Priority 2：同位素包络一致性（M3）

#### 理论基础

L 的元素组成（由序列 + 修饰精确决定）唯一决定其同位素包络：

$$\text{envelope}_{\text{pred}} = [I_M, I_{M+1}, I_{M+2}, I_{M+3}, ...]$$

H 是 L 的重标版本，元素组成几乎相同（仅 ¹²C → ¹³C 和 ¹⁴N → ¹⁵N 替换在 K/R 上），因此 H 的包络与 L 形状相同，整体平移 Δm。

三类独立可观测预测：

1. **包络比例**：M:M+1:M+2:M+3 的相对强度——由元素组成决定
2. **多通道共流出**：各通道 XIC 在 RT 维度同步——同肽段必同步
3. **绝对位置**：各通道精确 m/z（与 Δm 的可观测一致）

关键性质：

- **基于 MS1 全扫描**——不进 DIA 隔离窗口 → **5Da 下不退化**
- **包络由元素组成唯一决定**——干扰肽段的包络几乎必然不同
- **独立于 Q1a/Q1b**——MS1 端、前体级；Q1a/b 是 MS2 端、碎片级

#### 计算流程

```
对每个 PSM L:
  1. 由 L 序列 + 修饰计算理论包络（pyteomics 精确卷积）：
     envelope_pred = [I_M_pred, I_M+1_pred, I_M+2_pred, I_M+3_pred]
     归一化（max = 1 或 sum = 1）

  2. 在 H 候选位置提取 max_iso_peaks 个 MS1 XIC：
     for k in [0, ..., max_iso_peaks-1]:
         mz_iso_k_H = mz_M_H + k * 1.00335 / charge
         XIC_iso_k = extract_ms1_xic(mz_iso_k_H, apex_rt_L ± window)

  3. 取各通道强度构成 envelope_obs：
     I_obs_k = AUC(XIC_iso_k)
     envelope_obs = [I_obs_0, ..., I_obs_K-1]（同样归一化）

  4. 计算包络相似度、单点比例、共流出度等特征
```

#### 衍生特征

**包络形状相似度**（保留 Pearson 和 chi2，cosine/KL 高度相关，先不做）：

| 特征名 | 公式 | 真值期望 | 说明 |
|--------|------|---------|------|
| `m3_envelope_pearson` | Pearson(envelope_obs, envelope_pred) | → 1.0 | 标准形状度量 |
| `m3_envelope_chi2` | Σ (I_obs_k − I_pred_k)² / I_pred_k | 小 | 卡方距离，可转 p 值 |

**单点比例约束**：

| 特征名 | 公式 | 真值期望 | 说明 |
|--------|------|---------|------|
| `m3_first_ratio_dev` | \|(I_M+1/I_M)_obs − (I_M+1/I_M)_pred\| | 小 | M/M+1 是最稳通道对 |
| `m3_argmax_match` | argmax(obs) == argmax(pred) ? 1 : 0 | 1 | 大肽段独立鉴别 |

**多通道共流出**（独立维度，最强）：

| 特征名 | 公式 | 真值期望 | 说明 |
|--------|------|---------|------|
| `m3_xic_pairwise_corr_mean` | mean(Pearson(XIC_k, XIC_j)) for k≠j | → 1.0 | ⭐核心：各通道共流出度均值 |
| `m3_xic_pairwise_corr_min` | min(Pearson(XIC_k, XIC_j)) | → 1.0 | 最弱通道对——单点污染检测 |
| `m3_apex_max_dev` | max(apex(XIC_k)) − min(apex(XIC_k)) | 小（< 1 cycle） | 单点形式的共流出度量 |

**数据充分性**：

| 特征名 | 公式 | 说明 |
|--------|------|------|
| `m3_observed_count` | 通过显著性判定的同位素峰数 | 实测可见通道数 |
| `m3_predicted_visible_count` | envelope_pred 中预测可见的通道数 | 用作对照 |
| `m3_valid` | observed_count >= 2 | 是否有足够数据 |

**与 Q1a 的关键区分**：

- `m3_envelope_pearson` 比较的是包络比例的形状相似 → 受单通道污染影响
- `m3_xic_pairwise_corr_mean` 比较的是各通道随 RT 的同步 → **独立**于包络比例。即使某通道被 isobaric 干扰污染（envelope 比例失真），共流出度仍能识别（污染通道与其他不同步）

这是 M3 最强的鉴别力来源。

#### 同位素重叠风险与校正

L 的 M+k 同位素峰可能与 H 的 M 通道发生 m/z 重叠，重叠条件：

$$k \approx \frac{\Delta m \cdot z}{1.00335}$$

各标记体系的重叠分析：

| 标记 | Δm | k 最接近值 | L 的 M+k 相对强度 | 校正必要性 |
|------|-----|-----------|------------------|-----------|
| K8 | 8.0142 | 8 | < 0.01% | 可忽略 |
| R10 | 10.0083 | 10 | < 0.001% | 可忽略 |
| K6 | 6.0201 | 6 | ~ 1% | 建议校正 |
| K4 | 4.0251 | 4 | ~ 5% | **必须校正** |

**K8R10 下 M3 第一阶段不需要校正**，代码框架预留校正接口适配其他标记体系：

```
对每个 H 同位素通道 m:
    overlap_k = round((Δm + m × 1.00335) × z / 1.00335)
    if overlap_k 在 L 的有效同位素范围 AND L_pred[overlap_k] > correction_threshold:
        envelope_obs_H[m] -= L_M_intensity_observed × L_pred[overlap_k]
```

#### 鲁棒性分析

**M3 的两道防线**：

1. **envelope 比例**——由 L 的元素组成决定，干扰肽段几乎必然不同。弱点：低信号下高阶通道不可见，退化为只看 M/M+1。
2. **多通道共流出**（`m3_xic_pairwise_corr_mean`）——同肽段必同步。干扰需"恰好在 4 个 m/z 位置都同时共流出于同一 RT"，概率极低。

**与其他特征族的独立性**：

- 与 Q1a/Q1b 独立：MS1 端 vs MS2 端
- 与 5Da 现象独立：基于 MS1 全扫描，不受 DIA 窗口宽度影响 → **不退化**
- M3 是补 Q1a 在共窗口下"可用碎片数减半"不足的关键特征族

#### 失败模式

| 失败模式 | 表现 | 处理 |
|---------|------|------|
| 极弱信号 | observed_count 低，envelope 噪声大 | m3_valid = False |
| 大肽段（>2500 Da） | argmax 应为 M+2 或 M+3 | argmax_match 仍正确判定（预测也为 M+2/M+3） |
| 单通道被 isobaric 污染 | envelope 失真 | `m3_xic_pairwise_corr_mean` 识别（污染通道与其他不同步） |
| K4/K6 等小标记 | 同位素重叠 | 启用校正接口 |

#### 超参

| 超参 | 默认值 | 含义 |
|------|--------|------|
| `m3_max_iso_peaks` | 4 | 提取的最大同位素通道数 |
| `m3_iso_method` | "exact" | "exact"（pyteomics 精确）/ "averagine"（近似） |
| `m3_intensity_method` | "auc" | "auc" / "max" |
| `m3_min_observed_count` | 2 | m3_valid 阈值 |
| `m3_enable_overlap_correction` | false | K8R10 下默认关闭 |
| `m3_overlap_correction_threshold` | 0.01 | 仅当 L_pred[overlap_k] > 此阈值时校正 |

#### 实现复杂度

中。可调用 pyteomics.mass.isotopic_composition 计算精确同位素分布；重用现有 MS1 XIC 提取管线。


### 4.4 Priority 3：跨碎片强度比一致性

#### 理论基础

SILAC 实验中所有真实 SILAC 对应共享同一个混标比（如 1:1）。**跨碎片**的 H/L 比应在小范围内集中。

#### 计算流程

```
对每个 PSM L:
  1. 仅收集 Q1a 输出的 TP 可分离碎片
     （含平移碎片，以及分窗口下的不平移碎片；
      共窗口下的不平移碎片因 L+H 叠加无法独立测量 H/L 比，不参与）
  2. 对每个 TP 碎片 i 计算 r_i = log2(I_H_i / I_L_i)
     其中 I_L_i 取 light XIC 的 AUC、I_H_i 取 heavy XIC 的 AUC
  3. 计算 r_i 序列的统计量
```

#### 衍生特征

| 特征名 | 定义 | 真值期望 |
|--------|------|---------|
| `silac_ratio_median` | log2(H/L) 中位数 | ≈ 0（1:1 实验） |
| `silac_ratio_mad` | MAD | 极小 |
| `silac_ratio_iqr` | IQR | 极小 |
| `silac_ratio_outlier_frac` | 偏离 ±1.5×IQR 的碎片占比 | 极小 |
| `silac_ratio_bias` | |中位数 − 实验设定比例| | 极小 |

#### 鲁棒性分析

- 真 SILAC 对：所有碎片受同一混标比驱动 → 比值集中
- 干扰污染：不同碎片受不同强度的干扰 → 比值发散
- 该特征是**多点约束**：单一干扰肽段无法系统性使所有比例同时偏向某固定值

#### 与 Priority 1 的关系

- P1 给"哪些碎片配对成功"
- P3 给"配对成功的碎片是否符合 SILAC 物理"
- 二者级联使用：先 P1 筛选配对，再 P3 验证物理一致性

### 4.5 Priority 4：联合峰形拟合

#### 理论基础

真 SILAC 对来自同一肽段在同一色谱条件下的洗脱，应共享峰形参数（apex μ、峰宽 σ）。可联合拟合一个共享 Gaussian（或 EMG）模型。

#### 计算流程

```
模型 1（共享 apex 和 sigma）:
  XIC_L(t) = A_L · exp(-(t-μ)² / 2σ²)
  XIC_H(t) = A_H · exp(-(t-μ)² / 2σ²)
  拟合参数 (μ, σ, A_L, A_H)，记残差 r1

模型 2（独立 apex，共享 sigma）:
  XIC_L(t) = A_L · exp(-(t-μ_L)² / 2σ²)
  XIC_H(t) = A_H · exp(-(t-μ_H)² / 2σ²)
  拟合参数 (μ_L, μ_H, σ, A_L, A_H)，记残差 r2
```

#### 衍生特征

| 特征名 | 定义 | 真值期望 |
|--------|------|---------|
| `joint_fit_residual` | r1 / (XIC 总能量) | 小 |
| `apex_separation` | \|μ_L − μ_H\|（模型 2 拟合） | 极小 |
| `joint_fit_improvement` | (r1 − r2) / r1 | 极小（共享 apex 已足够） |
| `peak_sigma` | 拟合得到的峰宽 | 在物理合理范围内 |

#### 鲁棒性分析

- 真 SILAC 对：模型 1 已能很好描述 → r1 小，r1 ≈ r2
- 干扰构成的"heavy"：来自不同肽段的峰 → 模型 1 残差大；放开 apex 后（模型 2）apex 分离明显
- 该特征是 Pearson 的强化版：Pearson 只问"形状像不像"，联合拟合问"是不是同一物理过程产生"

#### 实现复杂度

中。使用 scipy.optimize.curve_fit；需处理拟合失败、低 S/N 等边界情况。

### 4.6 Priority 5：多电荷态交叉验证

#### 理论基础

同一肽段在多个电荷态下应同时被观测，且 RT 完全一致。

#### 计算流程

```
对每个 PSM L（鉴定在电荷态 z）:
  对其他电荷态 z' ∈ {z-1, z+1, z+2}（限于合理范围 2~5）:
    1. 计算 light 在 z' 电荷态的 m/z
    2. 在该 m/z 提取 XIC，检查 RT 是否与 z 电荷态一致
    3. 同样检查 heavy 在 z' 电荷态的 m/z
    4. 若 light 和 heavy 在 z' 都存在 → 一次跨电荷态确认
```

#### 衍生特征

| 特征名 | 定义 |
|--------|------|
| `multi_charge_light_count` | light 在多少个电荷态可见 |
| `multi_charge_pair_count` | SILAC 配对在多少个电荷态成立 |
| `multi_charge_rt_mad` | 跨电荷态 RT 的 MAD |

#### 鲁棒性分析

- 独立观测通道。干扰肽段在多个电荷态都骗过的概率 ~ 单电荷概率^k

#### 注意事项

- 并非所有肽段在多个电荷态都强 → 该特征可能缺失
- 需作为"奖励"而非"惩罚"使用（缺失时不参与判别）

## 五、判据形式升级（可选但推荐）

### 5.1 从单一分数到联合 p 值

**当前形式**：30 个特征 → 一个 ML 模型 → 单一分数 → 阈值

**升级形式**：每个独立维度（5 个特征族）→ 独立判别器 → 各自一个统计量 / p 值 → 联合（Fisher 或 Stouffer 方法）→ 联合 p 值

#### 优点

1. **显式编码独立性结构**：联合 p 值的有效性依赖独立性，强制设计者保证独立性
2. **理论意义**：联合 p 值不依赖 TDA 校准，可作为独立的可信度估计
3. **可解释性**：每个 PSM 的拒绝可追溯到具体维度——可以说"该 PSM 在 P1/P3 维度未通过"

#### 实施路径

1. 对每个特征族 Pᵢ 训练独立判别器，输出该族的鉴别分数 sᵢ
2. 在已知负样本上估计每个分数的零分布 → 转化为 p 值 pᵢ
3. 用 Fisher's combined probability test 合并：χ² = -2 Σ ln(pᵢ)，df = 2k
4. 校准检验：在已知真假数据集上检验联合 p 值是否近均匀分布

### 5.2 各维度独立性验证

独立性是联合检验的前提，必须通过实验验证而非仅靠理论分析。验证方法：

1. **相关性矩阵**：在大规模 PSM 上计算各特征族输出之间的 Spearman 相关
2. **退化同步性测试**：检查 2Da → 5Da 退化幅度的相关——同步退化 = 存在共同失败机制
3. **条件独立性检验**：在已知正样本子集和已知负样本子集分别检查独立性
4. **置换检验**：随机打乱某一特征族的 PSM 标签，检查联合判别器性能下降——下降应小于该族独立 KS 的暗示水平

## 六、验证协议

### 6.1 性能目标

| 数据集 | 当前 AUC | 目标 AUC |
|--------|---------|---------|
| 2Da only | 0.968 | 维持 ≥ 0.96 |
| 2Da + 5Da 混合 | 0.838 | ≥ 0.90 |
| 5Da only | 0.659 | ≥ 0.85 |

附加关注：

- **5Da 负样本召回**（当前 ≈ 0%）应达 ≥ 50%
- **5Da 负样本精确**应达 ≥ 80%
- **训练-测试无泄漏**：所有 AUC 在 Rep1+2 训练、Rep3 测试的设置下报告

### 6.2 与 TDA 的对照实验

**实验设置**：

1. 在标准 entrapment 数据集上同时运行 TDA 和 SILAC-validation
2. 将 PSM 分类为四类：
   - TDA 通过 & SILAC 通过 → 高置信
   - TDA 拒绝 & SILAC 拒绝 → 一致拒绝
   - TDA 通过 & SILAC 拒绝 → **TDA 可能高估**（重点分析）
   - TDA 拒绝 & SILAC 通过 → **TDA 可能误杀**（重点分析）
3. 对不一致案例做半自动验证（人工核查 + 物理特征汇总），统计 TDA 与 SILAC 哪一方更接近真值
4. 按肽段长度、修饰类型、电荷态、搜索引擎种类分桶，研究系统性偏差

**核心论文贡献候选**：

- 是否存在系统性的 TDA 失效模式？（按肽段类型分桶的失效率统计）
- 当 SILAC-validation 与 TDA 不一致时，哪些特征族提供了关键的反驳证据？
- SILAC-validation 在哪些场景下也会失效？（见 §6.3）

### 6.3 失败模式刻画

预计 SILAC-validation 在以下条件失败，需要系统量化：

| 失败条件 | 机制 | 量化方法 |
|---------|------|---------|
| 真共流出且巧合配对 | 另一肽段恰好满足所有维度 | 在已知真假数据上分析 false negative 的物理特征 |
| 低强度重标 | H 信号低于检测限 → 所有维度退化 | 按 light intensity 分箱，绘制 AUC vs intensity 曲线 |
| 修饰肽段 | 修饰可能改变 K/R 数 | 比较修饰 vs 非修饰肽段的 AUC |
| 极宽窗（≥ 25Da MSE/SWATH） | MS2 端干扰极重 | 模拟扩窗实验（如有数据）或人工干扰注入 |
| 短肽段 | 碎片数太少 → P1 失效 | 按肽段长度分箱的 AUC |

每种失败模式需给出：

1. 数据集构造方式（人工注入或筛选）
2. AUC 退化量化
3. 该条件下特征族独立性是否依然成立

## 八、风险与开放问题

### 8.1 已识别风险

1. **Priority 1 实现复杂度高**：碎片级 XIC 提取的工程量大，需要小心设计以保证性能（当前管线已优化前体级 XIC，扩展到 ~10× 碎片需评估内存/时间影响）
2. **理论同位素分布的不确定性**：averagine 模型在非典型氨基酸组成下有偏差；可能需要精确元素组成计算
3. **独立性可能在某些场景下被打破**：例如低 S/N 下所有维度同时退化，联合 p 值会高估可信度
4. **目标 AUC 可能过于乐观**：5Da AUC 从 0.659 到 0.85 是大跨度提升，需要预留计划备选

### 8.2 开放问题

1. **如何定义"通过 SILAC-validation"的阈值？** 是用固定 p 值阈值，还是按 FDR 控制？
2. **是否应支持非 1:1 的 SILAC 实验？** 当前设计假设 1:1，对其他比例需要参数化
3. **跨 raw file 的证据是否应汇总？** 同一肽段在 9 个 raw file 中可能多次出现，每次独立验证 vs 联合验证的权衡
4. **是否应回流到搜索引擎？** SILAC-validation 的结果能否反过来改进搜索引擎的评分？
