#这是什么 What is it

搜索引擎靠匹配理论谱图鉴定肽段，质控主流是 target-decoy。ms2-met 提供一条正交验证：同一肽段的轻标 / 重标两种形式 RT 相近、XIC 峰形相似。对一条轻标鉴定，按序列算出重标 m/z，在 DIA 谱图里找重标证据——若轻 / 重标 XIC 峰形高度相关 (Pearson 高) 则鉴定可信，否则疑似假阳性。最终把相关性等特征输出到 CSV，供训练 / 分析。

A light identification implies a heavy twin (+8.014 on K, +10.008 on R). We compute the heavy m/z, extract its XIC from the DIA run, and score the light-vs-heavy peak-shape correlation. High correlation ⇒ trustworthy ID; low ⇒ likely false positive. Features are written to a CSV for downstream training/analysis.

#快速上手 Quickstart

▸ 1 · 主流程特征提取 run feature extraction
$ python main.py --configpath config.ini --logpath ms2.log # 输出 result.csv（基本信息列 + XIC 相关性等特征列）
▸ 2 · 批量跑多窗口 baseline Makefile targets
$ make 2th # 2Da 窗口 $ make 5th # 5Da 窗口 $ make normal # 变窗 $ make all # 顺序全跑
▸ 3 · 构造多引擎数据集 build union dataset
$ python tools/extract_common.py --configpath extract_2da_pfind_diann.ini
▸ 4 · 训练 / 评估分类器 train scorer
$ cd tools/spec_trainer $ python src/main.py --config config/<name>.yaml --name <name>
▸ 5 · 读取 pFind 谱库 read spectral library (standalone)
$ python -m tools.speclib_inspect --library-dir <谱库目录> \ --fasta merge_human_ecoli_yeast.fasta --mod modification.ini \ --element element.ini --aa aa.ini --mass-limit 300000

#关键配置 Key config (config.ini)

键 key说明 description
search_engine_type0 自定义 JSON / 1 DIA-NN / 2 AlphaDIA / 3 pFind
feature_type0 同文件配对（陷阱库负例）/ 1 轻重标双文件
mass_tol_ppm质量容差（ppm），缺省 10
xic_cycle_windowXIC 提取的周期半窗
centroid_enabled / centroid_rel_threshold加载 mzML 时是否质心化 + 阈值（推荐 1e-3）
work_directory工作目录（缺省 ./workspace）；每个 baseline 可独立避免并行写冲突
result_file输出 CSV 路径
